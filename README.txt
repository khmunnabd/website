GitHub Pages:
1. Upload all files and the assets folder to the ROOT of your photo repository.
2. Ensure index.html is in the repository root.
3. In Settings > Pages, use GitHub Actions or Deploy from a branch (main / root).
4. If using GitHub Actions, make sure the workflow uploads the repository root as the Pages artifact.

Notes:
